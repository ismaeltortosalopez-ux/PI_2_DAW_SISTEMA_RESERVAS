# Sistema web para la gestión y reserva de espacios universitarios

## Descripción del proyecto

Este proyecto consiste en desarrollar una aplicación web que permita gestionar y reservar espacios universitarios de forma sencilla y organizada.

El objetivo principal es facilitar la consulta de la disponibilidad de aulas y otros espacios de la universidad, permitiendo a los usuarios realizar reservas y gestionar sus solicitudes.

## Funcionalidades principales

- Registro e inicio de sesión de usuarios.
- Consulta de espacios universitarios disponibles.
- Visualización de horarios y disponibilidad.
- Realización y gestión de reservas.
- Administración de espacios y reservas.

## Estado del proyecto

Actualmente, el proyecto se encuentra en la fase de planificación y organización. Se está preparando la estructura de la aplicación y definiendo las funcionalidades que se desarrollarán.
